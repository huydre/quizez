# UC-AI-01: Generate Word Set with AI

| **Use Case ID:** | UC-AI-01 |
| ---: | :--- |
| **Use Case Name:** | Generate word set with AI |
| **Created By:** | Quizez BA | **Last Updated By:** | Quizez BA |
| **Date Created:** | 2026-09-18 | **Date Last Updated:** | 2026-09-18 |

| **Actor:** | **Primary:** Learner (registered self-learner). **Secondary:** LLM Service (server-side language model that generates vocabulary cards). |
| ---: | :--- |
| **Description:** | When a learner wants to build a word set around a topic without typing every card manually, the learner opens the AI generation dialog, describes the topic or goal in a prompt, selects the target language and the desired card count, and lets the system generate a draft card list (term, definition, part of speech, example). The learner reviews and edits the draft, then saves it as a word set. The UC ends when the generated cards land in the word set edit form (UC-WSET-01) ready for the learner to save. |
| **Preconditions:** | 1. Learner is authenticated (valid session).<br>2. Learner has not exhausted the AI generation quota applicable to their account tier.<br>3. LLM Service is reachable from the backend. |
| **Postconditions:** | 1. A draft card list generated by the LLM Service is appended to the card list of the word set being edited.<br>2. Each generated card carries a non-empty term and definition; part of speech and example are populated when returned.<br>3. The learner's AI generation quota is decremented by one request.<br>4. No word set is persisted until the learner saves the parent form (see UC-WSET-01 / UC-WSET-03). |
| **Priority:** | High — flagship AI ingestion path; key differentiator vs. manual entry and a premium value driver. |
| **Frequency of Use:** | ~2–4 generations per active learner per month; peak during onboarding and exam-prep seasons. [TBD-1] |
| **Normal Course of Events:** | 1. Learner clicks the **Generate with AI** button in the word set form.<br>2. System displays the AI generation dialog with a prompt field, a target-language selector, a difficulty selector (default: Intermediate), and a card-count selector (default: 20).<br>3. Learner enters a topic or goal description in the prompt field (e.g., "IELTS vocabulary about the environment").<br>4. Learner confirms or adjusts the target language, difficulty, and card count.<br>5. Learner clicks the **Generate** button.<br>6. System sends the generation request to the LLM Service with the prompt, language, difficulty, and count.<br>7. LLM Service returns a list of candidate cards, each with term, definition, part of speech, and example sentence.<br>8. System displays the generated cards in a review table with per-card edit and remove controls.<br>9. Learner reviews the draft cards and edits or removes individual cards as needed.<br>10. Learner clicks the **Add to word set** button.<br>11. System appends all remaining draft cards to the word set's card list.<br>12. System closes the dialog and displays the updated card list in the word set form. |
| **Alternative Courses:** | **UC-AI-01.AC.1: Regenerate individual cards**<br>At step 9, if the learner is dissatisfied with specific cards but not the whole list:<br>9a. Learner selects one or more cards and clicks the **Regenerate selected** button.<br>9b. System requests replacements from the LLM Service for the selected terms only.<br>9c. System swaps the regenerated cards into the review table in place → continue from step 9 of the Normal Course.<br><br>**UC-AI-01.AC.2: Regenerate the whole list with adjusted settings**<br>At step 9, if the learner wants a different overall result:<br>9a. Learner clicks the **Regenerate all** button.<br>9b. System reopens the generation dialog pre-filled with the previous prompt and settings.<br>9c. Learner adjusts the prompt, difficulty, or card count and clicks **Generate** → continue from step 6 of the Normal Course.<br><br>**UC-AI-01.AC.3: Generate into a new word set**<br>At step 1, if the learner starts from the AI tools page instead of an open word set form:<br>1a. Learner opens the **AI Generator** page and clicks **New word set with AI**.<br>1b. System displays the same generation dialog → continue from step 3 of the Normal Course; at step 11 the system creates a new unsaved word set containing the generated cards and opens it in the edit form. |
| **Exceptions:** | **UC-AI-01.EX.1: LLM Service timeout or failure**<br>Trigger: At step 6–7, the LLM Service does not respond within the configured timeout or returns an error.<br>Response: System displays "AI generation is unavailable right now — please try again" with a **Retry** button and does not consume the learner's quota.<br>Final state: Dialog remains open with the learner's prompt and settings preserved; no cards added.<br><br>**UC-AI-01.EX.2: Generated content flagged as unsafe**<br>Trigger: At step 7, the LLM Service response or the learner's prompt is rejected by content-safety screening.<br>Response: System displays "This request can't be processed — please rephrase your topic" and clears the generated output.<br>Final state: Dialog remains open; learner may edit the prompt and resubmit; quota is not consumed.<br><br>**UC-AI-01.EX.3: Zero cards generated**<br>Trigger: At step 7, the LLM Service returns an empty list or only unparseable items.<br>Response: System displays "No vocabulary could be generated for this topic — try a more specific prompt" and offers **Regenerate all**.<br>Final state: No cards added; learner may adjust the prompt via AC.2.<br><br>**UC-AI-01.EX.4: Rate limit / quota exhausted**<br>Trigger: At step 5, the learner's account has no remaining AI generation quota for the current period.<br>Response: System displays the quota-exhausted message with the reset date and an upgrade prompt (see UC-PREM-01).<br>Final state: Generation is not attempted; dialog remains open; learner's input is preserved. |
| **Includes:** | UC-WSET-01: Create word set manually (the generated cards land in this form for saving — invoked at step 11). |
| **Special Requirements:** | **Performance**: Generation of up to 50 cards completes ≤ 30s end-to-end; the dialog shows a progress indicator after 3s.<br>**Security**: Prompts are sent server-side only; the LLM provider key is never exposed to the client; generated content is sanitized before rendering.<br>**Reliability**: A failed generation never consumes quota; duplicate submissions are deduplicated by request id.<br>**Compliance**: Generated content passes the platform content-safety policy before display. |
| **Assumptions:** | 1. Free-tier learners have a limited monthly AI generation quota; premium raises or removes the cap (per UC-PREM-01).<br>2. The LLM Service can produce term/definition/POS/example for all supported target languages.<br>3. Learners review AI output before saving — generated cards are drafts, not trusted content. |
